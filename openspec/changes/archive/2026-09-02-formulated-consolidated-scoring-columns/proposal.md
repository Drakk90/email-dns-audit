# Proposal: Formulated Consolidated Scoring Columns

## Intent

The `Cumplimiento Global` column in the Consolidated Summary worksheet currently stores a static precalculated decimal value (`0.65`, `0.50`, `0.58`) generated by Python. External stakeholders, auditors, and CISOs viewing the workbook cannot audit or trace how individual protocol checks contribute to the overall score. This change introduces four formulated pillar scoring columns and formulates the global compliance percentage directly inside Excel.

## Scope

### In Scope
- Add 4 formulated score breakdown columns to `Resumen_Consolidado` / `Consolidated_Summary`:
  - `Score Autenticación (40)` / `Auth Score (40)`
  - `Score Transporte (25)` / `Transport Score (25)`
  - `Score DNS/Identidad (20)` / `DNS & Identity Score (20)`
  - `Score Superficie EASM (15)` / `EASM Score (15)`
- Formulate `Cumplimiento Global` / `Global Compliance` as `=(Score_Auth + Score_Trans + Score_DNS + Score_EASM) / 100` with number format `0.0%`.
- Update executive cover sheet card formulas (`Score CISO` and `Cumplimiento Promedio`) to reference the relocated compliance column (column `AB`).
- Centralize bilingual headers for the new columns in `i18n.py`.

### Out of Scope
- Modifying underlying scoring weights (Auth 40%, Transport 25%, DNS 20%, EASM 15% remain canonical).
- Adding custom Excel VBA macros.

## Capabilities

### New Capabilities
None.

### Modified Capabilities
- `excel-report-exporter`: Expand `Consolidated_Summary` schema with 4 formulated sub-score columns and formulate the global compliance column.

## Approach

1. **Workbook Schema Expansion**:
   - Insert 4 pillar columns after column W (`BIMI Publicado`) in `Resumen_Consolidado`.
   - Global Compliance moves from column 24 (`X`) to column 28 (`AB`).
2. **Dynamic Bilingual Formula Injection**:
   - Inject native OOXML formulas in each row `r`:
     - Auth: `=IF(OR(J{r}="si",J{r}="yes"),IF(AND(OR(K{r}="-all",K{r}="~all"),N{r}="no",L{r}<=10),15,8),0) + IF(OR(O{r}="si",O{r}="yes"),IF(P{r}="reject",20,IF(P{r}="quarantine",14,5)),0) + IF(COUNTIF('{dkim_sheet}'!B:B,A{r})>0,5,0)`
     - Transport: `=IF(U{r}="enforce",15,IF(U{r}="testing",8,0)) + IF(OR(V{r}="si",V{r}="yes"),10,0)`
     - DNS/Identity: `=IF(OR(I{r}="Secure",LEFT(I{r},7)="Firmado"),15,IF(LEFT(I{r},10)="Incompleto",5,0)) + IF(OR(W{r}="si",W{r}="yes"),5,0)`
     - EASM: `=MAX(5, 15 - MIN(10, COUNTIFS('{easm_sheet}'!A:A,A{r},'{easm_sheet}'!D:D,"<>No")*3))`
     - Global Compliance: `=(X{r} + Y{r} + Z{r} + AA{r}) / 100`
3. **Cover Sheet Retargeting**:
   - Update `A5`, `J5`, and `M5` formulas to target column `AB` instead of `X`.
